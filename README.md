# Student Performance Analysis Using MATLAB

## Project Description
This project analyzes student academic performance using MATLAB and statistical techniques.

## Objectives
- Calculate mean, median, mode, range, variance and standard deviation.
- Analyze correlation between attendance and examination marks.
- Predict examination marks using linear regression.
- Compare two student groups using a two-sample t-test.
- Generate graphical representations of results.

## Technologies Used
- MATLAB
- Statistical Analysis
- Linear Regression
- Data Visualization

## Project Files
- student_performance.m – Main MATLAB source code.
- output_screenshots – Project graphs and results.

## Conclusion
The project demonstrates the use of MATLAB for statistical analysis, prediction and visualization of student academic performance.
